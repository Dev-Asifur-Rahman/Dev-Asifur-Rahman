<h1 align="left">About me</h1>

<p align="left">Hi, I'm Asifur Rahman, a passionate web developer from Bangladesh and a final-year Computer Science and Engineering student at Manarat International University, graduating in May 2025. I have a strong interest in full-stack development, especially using the MERN stack, and I enjoy building modern, interactive, and user-friendly web applications.
